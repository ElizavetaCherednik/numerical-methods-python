# Численные методы и программирование на Python

Репозиторий с практическими работами по дисциплине «Численные методы и программирование». 
Здесь представлены решения прикладных экономических и вычислительных задач с использованием Python и библиотеки NumPy.

## Что внутри

* **`01_economics_tasks.py`** — Практическая работа №1: 
  * Работа с функциями и lambda-выражениями
  * Декораторы
  * Векторизация вычислений (`np.vectorize`)
  * Булева индексация и срезы массивов
  * Матричные операции (Broadcasting)
  * Решение системы линейных уравнений модели Леонтьева (`np.linalg.solve`)

* **`02_numerical_methods.py`** — Практическая работа №2:
  * Графический метод локализации корней (Matplotlib)
  * Метод дихотомии (бисекции)
  * Метод Ньютона (касательных)
  * Метод простой итерации

## Используемые технологии
* **Python 3.x**
* **NumPy** — массивы, линейная алгебра, векторизация
* **Matplotlib** — визуализация данных и графиков
* **math** — стандартные математические функции
